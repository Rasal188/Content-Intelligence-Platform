# PROJECT RULES

This repository is an existing production SaaS template.

The goal is to ADD an AI Content Analyzer module.

NOT build a new application.

Rules

1. Never refactor unrelated code.
2. Never rename folders.
3. Never move existing files.
4. Reuse existing UI.
5. Reuse existing layouts.
6. Preserve dashboard architecture.
7. Build one feature at a time.
8. Every feature must compile before continuing.
9. Never modify unrelated Convex logic.
10. Dashboard-first development.
